1. Parties & purpose

This Statement of Work V2 (“SOW”) is between Maple AI Technologies (“Maple AI”) and Munjal Universal Consultancy Private Limited, operating as Merrakii+ (“Merrakii”). It defines Phase 1 delivery for the Merrakii+ DESSS web application as a product engineering engagement: build and ship the scoped student-facing pages, admin capabilities, and supporting backend listed below.

Phase 1 is one responsive web application (mobile through desktop; browser-based, not native apps). Merrakii owns content, vendor accounts, and AWS usage. Maple AI owns architecture, implementation, integrations agreed herein, UAT support, and handover.

2. Scope source of truth

  • In scope: every row in New Website Pages where Phase 1 = Yes (40 items across Student Facing, Admin Panel, and Backend).
  • Out of Phase 1: rows not marked Phase 1 = Yes (listed in Section 5), plus native mobile apps and any work not named in this SOW.
  • Prior product surface: earlier Merrakii marketplace routes are reference only (Section 6); Phase 1 rebuilds the DESSS experience, not a like-for-like catalogue clone.

4. Integrations, hosting & non-functionals

Boundary. Maple AI integrates and deploys using credentials Merrakii supplies. Merrakii owns vendor contracts, payment KYC, AWS account billing, and usage fees.
  • Payment: Journey and course payment pages plus payment integration as listed under Student Facing (UPI and agreed gateways per Design sign-off).
  • Access & security, search & personalisation, integrations, responsiveness, data & architecture, workflows, DevOps, compliance: as listed under Backend Phase 1 rows.
  • Hosting: AWS staging and production on Merrakii’s account; Maple AI supports setup, deploy pipeline, monitoring baseline, and runbook.
  • Targets: usable on modern mobile and desktop browsers; RBAC on authenticated APIs; WCAG 2.1 AA on public marketing/legal pages where applicable.

8. Acceptance criteria

  1. Each Section 3 Phase 1 = Yes topic is demonstrable on staging (and production at go-live) at the agreed fidelity for its type (Page / Integration / Backend).
  2. Client-provided templates and content called out under Requirement are incorporated when supplied on time; placeholders are acceptable where Merrakii input is late, with documented follow-up.
  3. No open Severity-1 defects for in-scope items at UAT sign-off; Severity-2 items listed with fix or workaround.
  4. Handover pack: AWS runbook, environment notes, content/admin guidance for Career Library, Courses, Resources, and User Management surfaces in scope.
